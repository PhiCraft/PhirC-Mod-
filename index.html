Phirc Mod++ 是基于 Phira 0.8.2 的社区改版：判定窗口可分别设置，实时数据可九宫格定位， 成绩有历史与趋势，界面字体与主题随你换。包名独立，可与官方版共存。

判定全可控

Perfect / Good / Bad 判定窗口可分别设置，附带 late 侧补偿。判定文字四种动画、字号、同色外发光任你调。

数据看得见

九宫格可定位 HUD：ACC、判定计数、最大连击、时间误差、预估 RKS、进度、FPS。Early-Late 实时提示同步显示。

成绩有历史

成绩历史页提供趋势图、判定分布、PB 对比与 JSON 导入导出。每日挑战常驻，进步曲线一目了然。

界面随你换

界面字体使用 HarmonyOS Sans，支持导入自定义字体；深浅主题切换，触点标记样式 / 颜色 / 透明度均可调。

iOS 安装步骤

以 AltStore / Sideloadly 为例，全程需要一台电脑。

  1. 在电脑上安装 AltStore（配合 AltServer）或 Sideloadly。
  2. 把上面的 .ipa 下载到电脑本地。
  3. 用数据线连接 iPhone，通过 AltStore / Sideloadly 选择该 ipa，使用你的 Apple ID 完成签名并安装。
  4. 在 iPhone 上打开「设置 → 通用 → VPN与设备管理」，信任对应的开发者证书。
  5. 回到桌面打开应用即可。免费 Apple ID 的签名 7 天后失效，需重新签名一次。
iOS 端未做签名分发，本页仅提供下载入口与通用安装说明。安装过程中产生的任何问题与风险由使用者自行承担。

FAQ

常见问题

会和官方版共存吗？

可以。Phirc Mod++ 的包名是 org.flos.phira.modded，与官方客户端不同，安装时不会覆盖官方版本，两个应用可以同时存在于同一台设备上。

不过两边的本地数据相互独立，不会自动同步。

会被封号吗？

本项目是社区改版，不对账号状态做任何保证，也不提供任何「规避检测」相关的能力或说明。

与账号相关的行为请自行判断：

  • 官方成绩上传默认关闭，不开启就不会上传任何成绩。
  • 开启前需要先阅读并同意免责协议。
  • 影响公平性的选项不会随成绩一并上传。
  • 是否开启、以及由此产生的一切后果，由使用者自行承担。

请遵守官方平台的使用条款。如果你在意账号状态，建议保持上传关闭。

怎么上传成绩？

上传功能默认关闭，需要在设置里手动开启。开启前必须先阅读并同意免责协议。

  • 只有成绩本身会上传；影响公平性的选项不会上传。
  • 开启后上传行为与官方账号关联，请确认你了解其含义。
  • 若绕过上述限制，后果由使用者自行承担。
iOS 为什么装不上？

因为分发的 .ipa 是未签名包。iOS 不允许安装未签名的应用，App Store 也不会收录这类社区改版。

解决办法是用 AltStore 或 Sideloadly 用自己的 Apple ID 重新签名后安装，具体步骤见「下载」区块。

  • 免费 Apple ID 的签名 7 天后过期，需要重新签名。
  • 每台设备同时可用的自签应用数量有限，安装多个应用时注意取舍。
  • 签名与安装过程中出现的问题，与本项目无关，风险由使用者自行承担。
存档在哪？

存档保存在各平台的应用私有目录中，与官方客户端相互独立。

  • Android：位于应用私有数据目录，普通文件管理器无法直接访问；可通过应用内的成绩导出功能导出为 JSON。
  • iOS：位于应用沙盒内；可通过应用内导出，或用 iTunes / Finder 的文件共享功能访问。
  • 卸载应用会一并删除存档，卸载前请先导出。
